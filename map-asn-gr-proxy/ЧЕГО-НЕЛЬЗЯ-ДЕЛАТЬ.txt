-----------------------------------------------------------------------------------
             запускать build_map_sources_serviceXXX.bat из папки, отличной от             
f:\map_parse\src\map_parse\src\asn1\asnc\ (регистр символа f:\ ткже имеет значение)
-----------------------------------------------------------------------------------

Иначе будет изменён КАЖДЫЙ файл в папке map-src.

-----------------------------------------------------------------------------------
добавлять или удалять стройки в .asn файлах
-----------------------------------------------------------------------------------

Иначе будет изменён каждый файл, декларации которого идёт после изменения номеров
строк.

-----------------------------------------------------------------------------------
                           комментировать REQUIRED поля                            
-----------------------------------------------------------------------------------

Неправильно:

    RequiredFieldsExampleArg ::= SEQUENCE {
        --unused:imsi [0] IMSI,
        msisdn [1] ISDN-AddressString OPTIONAL }

Правильно:

    RequiredFieldsExampleArg ::= SEQUENCE {
        imsi [0] IMSI, --unused
        msisdn [1] ISDN-AddressString OPTIONAL }

-----------------------------------------------------------------------------------
           комментировать OPTIONAL поля встречающися перед используемыми           
-----------------------------------------------------------------------------------

Неправильно:

    OptionalFieldsExampleArg ::= SEQUENCE {
        --unused:imsi [0] IMSI OPTIONAL,
        msisdn [1] ISDN-AddressString OPTIONAL }

Правильно:

    OptionalFieldsExampleArg ::= SEQUENCE {
        imsi [0] IMSI OPTIONAL, --unused
        msisdn [1] ISDN-AddressString OPTIONAL }

-----------------------------------------------------------------------------------
комментировать OPTIONAL поля встречающиеся после используемых, не заменяя их на ...
-----------------------------------------------------------------------------------

Неправильно:

    OptionalFieldsExampleArg ::= SEQUENCE {
        imsi [0] IMSI OPTIONAL,
        msisdn [1] ISDN-AddressString OPTIONAL
        --unused:extensionContainer ExtensionContainer OPTIONAL,
        --unused:... }

Правильно:

    OptionalFieldsExampleArg ::= SEQUENCE {
        imsi [0] IMSI OPTIONAL,
        msisdn [1] ISDN-AddressString OPTIONAL,
        --unused:extensionContainer ExtensionContainer OPTIONAL,
        ... }
